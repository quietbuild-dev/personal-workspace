# Confirmed final usability corrections (26 November 2026)

This patch implements the user's 14 approved changes without altering user databases, Git history, or the accepted-plan Undo code. Changes are installed only on a feature branch after a source compatibility check. **No automatic commit or push.**

## Scheduling behavior

- **Energy Today** only divides sessions already accepted on the selected date. It never adds tasks, increases study minutes, or moves work onto other dates. The rest of the accepted week remains unchanged. Session division conserves the original total time.
- **Make Room for Life** changes only future booked study sessions that overlap the requested protected windows. It prefers a single relocated block, and if necessary splits a conflicting session into at most three blocks of **at least 20 minutes each**. Existing unrelated study sessions stay unchanged. If no compliant placement exists, approval is disabled.
- New sessions generated by the greedy planner and CP-SAT require at least 20 minutes; tiny remaining work is reported as a shortfall instead of becoming an unusable session. Previously accepted short sessions are not silently deleted.
- Both scoped features reuse the existing validated preview, explicit approval, transactional save, and Undo implementation. Preview never writes data. The untouched planner's goal selection and other Calendar functionality remain available.

## Calendar and UI

- Schedule Check's "Review my week" no longer assigns to the existing `calendar_browse_date` widget key after it was rendered; the button requests a fresh plan instead.
- Free Time shows only affected study sessions, how many remain unchanged, and a concise feasibility result. Unrelated solver diagnostics and a duplicated timeline are not shown there.
- Remaining before/after comparisons use explicit vertical tick positioning and spacing.
- Onboarding groups name and focus hours together, and the distribution labels are **Spread evenly / Fewer study days / No preference**. Preferred-hours selection remains interactive and changes are saved only on request.
- The Daily Briefing says **No study planned** for zero hours and separately counts approaching deadlines through Sunday and overdue deadlines.
- Simple to-dos in Today's Focus offer **Done** directly, while progress-based assignments retain **View task**.
- Weekly workload categories form continuous stacked columns with rounded outer corners; the redundant chart disclaimer is removed.
- Weekly Replay shows the number of genuinely completed tasks using task completion timestamps, plus separately logged completed study sessions and actual study minutes. Checking off a task does not create fictional study hours.
- Large persistent green success banners on Home, Tasks, Calendar, and Settings are replaced with compact notifications; other warnings remain visible.
- Settings explanations are shorter and less technical.

## Deliberate limits

- The selected Energy option was **scoped adaptation**, not an energy/concentration redesign. Low Energy now changes only the boundaries of already accepted work; it does **not** lower today's total study obligation or reserve breaks. The UI says so.
- Scoped Free Time is conservative: it refuses an adjustment rather than moving unrelated commitments, missed/done sessions, or required deadline work. Existing social/exercise commitments remain permitted.
- Historic study-completion data are recorded only when a user logs actual time; past work cannot be reconstructed automatically.
